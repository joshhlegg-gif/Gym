# Gym

A training and body-composition tracker. Weigh-ins, trends, periodisation
phases with their own decision rules, and a training log built around load
progression rather than tonnage.

Replaces a colour-coded Google Sheet. Runs on iPhone, Mac and PC.

- **[`docs/spec.md`](docs/spec.md)** — the product spec. Authoritative.
- **[`CLAUDE.md`](CLAUDE.md)** — the engineering contract.
- **`lib/calc/`** — every calculation, pure and unit tested.

```
npm install
npm test
npm run typecheck
```
